# Code refactor log

Sequential record of the bug-fix + architecture work planned in SPEC.md section 12. One row per step; each step is one commit and ends with `npm run typecheck` and `npm test` green. The golden rule: existing functionality does not break — enforced by the golden fixtures introduced in step 0.

| Rule | How it is enforced |
| --- | --- |
| Behaviour frozen | `tests/golden.test.ts`: 27 page HTML files (byte-for-byte), 32 image/export outputs (SHA-256 + size + contract headers), 4 Android ZIPs (entry names, sizes, per-image hashes, README minus timestamp) in `tests/fixtures/golden/` |
| Intentional changes only | Fixtures are regenerated with `node tests/golden.update.ts` only when a step changes behaviour on purpose; the step's row says which fixtures changed and why |
| Test first | Every bug step adds a failing test before the fix |
| One step = one commit | `git log` mirrors this table |
